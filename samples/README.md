# Dhrystone sample image

`dhrystone.bin` is a test image for the Ghidra module, made from GCC-compiled Dhrystone.

| File | Contents |
|---|---|
| `dhrystone.bin` | The raw image: 534 words (1,068 bytes), big-endian, loaded at word 0 |
| `dhrystone.tsv` | The listing: one row per word, with the disassembly the source intends |
| `dhrystone.map` | Section and symbol addresses |

**It tests disassembly and has never been run.** It was assembled by this repo's test
assembler, not as1750, and its layout is not the one as1750 would produce.

To open it in Ghidra, import it as Raw Binary with the language `MIL1750A:BE:16:default`
and base address 0, then disassemble at word 0.

## Image layout

All addresses are 16-bit word addresses, which is what Ghidra shows for this language.
A word's offset in the file is its address times 2, with the most significant byte first.

| Words | Size | Section | Contents |
|---|---|---|---|
| `0000`–`0006` | 7 | Startup | Generated by the assembler, see below |
| `0007`–`01D1` | 459 | Normal | Program code from `dhry.s`, `__main.s` and `bcopy.s`, in that order |
| none | 0 | Stubs | One `URS R15` per undefined symbol; this program has none |
| `01D2`–`020D` | 60 | Konst | Constants and `static` data, including zero-filled `block` space |
| `020E`–`0214` | 7 | Init | Compiler startup code that copies initial data out of Konst |
| `0215` | 1 | Final return | `URS R15`, which ends Init and the image |
| `0216`–`05F1` | 988 | Common | Uninitialized globals. **Addresses only, not in the file** |
| `F000` | | Stack | Initial `R15`, not in the file. The stack grows down |

Addresses `0216` and up aren't in the file, so Ghidra has no memory block there by default.
Instructions still show those addresses as operands.

### Startup

```
0000  LIM R15,0xF000     set the stack pointer
0002  SJS R15,0x020E     call Init
0004  SJS R15,0x014E     call MAIN
0006  BR  0x0006         stop by branching to itself
```

### Code inside Normal worth knowing about

- **Jump table:** `00BB`–`00BF` are 5 data words inside the code, read by `JC 0xF,0x0,R1`
  at `00B9`. They must not decode as instructions.
- **Unreachable by flow:** the switch cases at `00C0`–`00D2` (10 instructions) are only
  reached through that table, so following flow from word 0 finds 312 of the 322
  instructions. Disassemble at those addresses by hand to get the rest.
- **`__MAIN`:** it has no body, so it shares address `01CE` with `BCOPY`. Nothing calls it.

Other symbols are in `dhrystone.map`. The file's own names are upper case because the
assembler folds case.

### How this differs from as1750

| | as1750 default | This image |
|---|---|---|
| Code start | `0x0100` | Word 0 |
| Init | Placed first, and runs straight into Normal | After Konst, called as a subroutine |
| Startup stub, final return | None | Added by the test assembler |
| Static | Its own section after Konst | Merged into Konst |
| Undefined symbols | Link error | Stub functions |

## Regenerating

Run this from a checkout of milstd1750tools at that commit, with `$REPO` set to this repo:

```sh
cd as1750/tests
python3 "$REPO/tests/sleigh/assemble_1750.py" -o dhrystone.bin -l dhrystone.tsv -m dhrystone.map \
  dhry.s __main.s bcopy.s
```
